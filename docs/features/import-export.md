# 导入导出

Metro Studio 支持从真实地图导入线网，并提供多种图片与数据导出方式。

![导出界面](/images/export.png)

## 导入

### 从 OpenStreetMap 导入

直接从 OSM 导入真实地铁线网数据，自动解析线路和站点信息。

### 导入项目文件

导入之前保存的 JSON 项目文件，恢复完整编辑状态。

## 导出

### 实际走向高清图

导出全网高分辨率 PNG，适合打印和细节检查。

### 分享用小图（全网）

导出全网小尺寸 PNG，适合聊天、社交平台和快速汇报。

### 官方风格图 PNG

导出规整的示意图风格线路图。

### 车辆 HUD 图打包导出

导出 ZIP 资源包，包含车辆 HUD 显示图。

### 项目文件

导出 JSON 项目数据，包含站点、线路和配置，方便备份和迁移。
