# components

UI 组件，负责交互与渲染。

## 根目录文件

- **App.vue** — 主布局容器（工作区三视图切换、无已打开工程欢迎页路由、页面关闭/刷新二次确认）
- **MapEditor.vue** — 基于 MapLibre 的真实地图编辑器（OSM 瓦片底图、站点点击/拖拽/添加站点/添加线段、AI 添加站点、连续布线、线段曲线渲染、锚点交互、框选、右键菜单、键盘快捷键；选中单站后支持 `PgUp` / `PgDn` 沿线路切换相邻站点，地图网格通过地理图层渲染并随平移/缩放同步；时间轴年份下的线路图例与换乘判断按共线段的按线路开通时间过滤；地图加载失败时会输出调试日志）
- **SchematicView.vue** — 渲染自动排版后的示意图（地理主导示意图、滚轮缩放、中键平移）
- **SchematicControls.vue** — 示意图视图排版工具面板内容（按“显示层 / 布局引擎 / 预设库”组织控件；支持“骨架展开 / 枢纽分流 / 紧凑程度 / 直线优先 / 标签避让”五轴语义降维控制，以及参数预设的选择、另存、覆盖、删除、导出、导入；修改参数后手动重新排版）
- **VehicleHudView.vue** — 车辆 HUD 视图（按线路 + 方向自动生成、线路/方向选择控件、换乘标识、方向箭头、环线双层闭合轨道、超长线折返）
- **TimelinePreviewView.vue** — 时间轴动画实时预览视图（Canvas 2D + requestAnimationFrame、播放控制、速度选择、全屏、伪"发展史"线序预览）
- **MenuBar.vue** — 顶部菜单栏（文件/编辑/视图/导出/统计/设置/帮助，含右上角建设年份与工程期数快捷设定，便于新绘制线段自动继承开通年份/分期标签；AI 入口并入编辑/设置菜单；线路切换器与下拉项图标按线路色显示；搜索地点与导航按钮使用统一 SVG 精灵图标；导航状态缺失时自动降级为空态）
- **NoProjectWelcome.vue** — 未打开工程欢迎页（按参考稿复刻：Canvas 网格粒子、三层色散故障字效、双操作卡片与右侧全息面板）；顶部副标题 ID 在组件挂载期固定，避免每次重渲染随机跳变
- **PropertiesPanel.vue** — 右侧 Inspector 容器（根据选中对象动态切换子面板，并将“对象属性 / 年份事件”拆分为独立 tab，统一头部摘要与面板语言）
- **LayoutControlsPanel.vue** — 左侧排版工具容器（统一 Tool Panel 头部、滚动区与执行区，底部固定“生成官方风示意图”主操作）
- **TimelineSlider.vue** — 时间轴滑块控件（年份筛选、播放控制；年份刻度“新开通”标记按共线段的按线路开通时间计算）
- **TimelineEventEditor.vue** — 时间轴事件编辑器（在右侧属性面板固定显示；支持新增自定义年份、同一年多条事件、按组设置“开通前/开通后/年度最后(全网)”展示时机，并支持逐条编辑/删除；支持按年设置“之前/之后”延时，延时输入实时写入项目状态，不依赖失焦触发；年份行的“线段数”按当年实际发生开通的共线归属统计；新增年份区与事件条目在窄屏下自适应重排）
- **StatisticsDialog.vue** — 统计信息弹窗（含线网概况、各线路排行、基础概况、路径分析、换乘枢纽、线路分析与可达性；路径栏位超长站名自动换行，避免撑宽弹窗；缺少可达性状态时自动降级为空态）
- **QuickNamingDialog.vue** — 快速命名对话框（按线路区间进入逐站命名模式，也支持一键连续命名全图或当前区间里仍使用默认中文名 `新站 X` 的站）
- **EnglishReviewDialog.vue** — 英文审查对话框（按线路区间逐站确认英文名，也支持一键翻译全图或当前区间里仍使用默认英文名 `Station X` 且未锁定的站）
- **ProjectListDialog.vue** — 项目列表对话框
- **ConfirmDialog.vue** — 确认对话框
- **PromptDialog.vue** — 输入对话框
- **ToastContainer.vue** — Toast 通知容器
- **ErrorBoundary.vue** — 错误边界组件
- **StatusBar.vue** — 底部状态栏（战术终端风标签与保存状态指示，展示当前编辑模式、保存状态与工程摘要；工程摘要按当前编辑年份统计已开通的线路归属，兼容共线段分年开通）
- **ToolStrip.vue** — 工具条组件（仅地图视图显示，窄栏悬浮玻璃样式与激活态强调；提供模式切换与撤销/重做，不再包含草稿笔/橡皮擦）
- **AccordionSection.vue** — 手风琴折叠面板
- **DropdownMenu.vue** — 下拉菜单
- **TooltipWrapper.vue** — Tooltip 包装器
- **IconBase.vue** — 图标基础组件
- **IconSprite.vue** — 图标精灵表
