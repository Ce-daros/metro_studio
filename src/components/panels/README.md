# components/panels

属性面板子组件。

## 文件说明

- **PanelNoSelection.vue** — 无选中对象时的工程 Inspector（工程统计、线路库下拉切换、当前线路编辑、危险操作）
- **PanelStationSingle.vue** — 单个站点 Inspector（对象摘要、命名编辑、位置与拓扑摘要、危险操作）
- **PanelStationMulti.vue** — 多个站点批量 Inspector（模板命名、AI 英文处理、换乘工具、危险操作）
- **PanelEdgeSingle.vue** — 单条线段 Inspector（真实当前值编辑、时间元数据、危险操作）
- **PanelEdgeMulti.vue** — 多条线段批量 Inspector（批量迁线、线型、曲线状态、时间元数据、危险操作）
- **PanelAnchor.vue** — 锚点 Inspector（几何上下文摘要、危险操作）
- **PanelAnnotation.vue** — 注释 Inspector（注释列表、正文编辑、危险操作）
